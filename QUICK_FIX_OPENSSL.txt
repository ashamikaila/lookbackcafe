║   QUICK FIX: OpenSSL Extension Missing Error             ║
╚═══════════════════════════════════════════════════════════╝

ERROR YOU'RE SEEING:
"Extension missing: openssl"

═══════════════════════════════════════════════════════════

✅ QUICK FIX (2 MINUTES) - ENABLE OPENSSL:

1. Open XAMPP Control Panel

2. Click "Config" next to Apache

3. Select "PHP (php.ini)"

4. Press Ctrl+F and search for: extension=openssl

5. You'll find this line:
   ;extension=openssl
   
6. Remove the semicolon (;) to make it:
   extension=openssl

7. Save the file (Ctrl+S)

8. In XAMPP Control Panel:
   - Click "Stop" for Apache
   - Wait 3 seconds
   - Click "Start" for Apache

9. Go to: http://localhost:8080/website/check_php_config.php
   - Verify OpenSSL shows "ENABLED"

10. Try sending email again!

═══════════════════════════════════════════════════════════

⚡ ALTERNATIVE: Use PHP mail() Instead (30 seconds)

If you can't enable OpenSSL right now:

1. Open: lookbackcafe/website/config/email.php

2. Find this line:
   define('USE_SMTP', true);

3. Change it to:
   define('USE_SMTP', false);

4. Save the file

5. Try sending email again!

Note: This method works but emails may go to spam folder.

═══════════════════════════════════════════════════════════
